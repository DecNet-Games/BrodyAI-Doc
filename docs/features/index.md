# 🛠️ Feature Overview

Brody AI contains a comprehensive set of modules integrated directly into the Unity Editor. These modules automate programming, scene orchestration, material construction, and audio asset generation.

---

## 🔍 Core Features Directory

*   [**AI Chat Agent & Workspace**](./ai-chat.html)
    Chat with your codebase, select files, examine hierarchy objects, and control active conversation sessions.
*   [**Co-Pilot Modes (Ask, Plan, Execute)**](./co-pilot-modes.html)
    Control whether the AI is allowed to write scripts/commands (Execute), outline step-by-step architectures (Plan), or answer conceptual questions (Ask).
*   [**Generate Component**](./generate-component.html)
    A dedicated overlay to spawn new C# scripts tailored for specific scene GameObjects.
*   [**Edit with AI**](./edit-with-ai.html)
    Surgical, context-aware script modifications directly from the Unity Inspector interface.
*   [**Texture Lab**](./texture-lab.html)
    Generate materials and PBR textures instantly inside the editor using free open endpoints.
*   [**Sound Lab**](./sound-lab.html)
    Generate game-ready SFX clips (explosions, footsteps, magic spells) using ElevenLabs.
*   [**Auto-Fix Engine**](./auto-fix.html)
    Automatic console diagnostic system that reads compile and runtime exceptions and offers one-click source patches.
*   [**Codebase Indexing**](./codebase-indexing.html)
    Under-the-hood vector indexing that keeps Brody updated on your scripts.
*   [**Scene Automation**](./scene-automation.html)
    Autonomous scene editing using simple layout syntax (Spawn, Move, Parent, Delete).
*   [**Dependency Graph**](./dependency-graph.html)
    Maps script dependencies to ensure edits don't break related classes.
*   [**Architecture Guard**](./architecture-guard.html)
    Protection rules that scan scripts for dangerous circular dependencies or infinite loops.
