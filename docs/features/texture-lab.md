# 🎨 Texture Lab (Free Material Generator)

**Texture Lab** is a visual asset creation tool built directly into the Unity Editor. It allows you to generate textures and materials from text descriptions.

---

## 🚀 How to Use

1.  Open **Tools > Brody AI > Texture Lab** (or access it from the Welcome Dashboard under Power Tools).
2.  Select your preferred **Image Provider** in the settings (default is Pollinations, which is free).
3.  Type a descriptive prompt (e.g. *"dark cobblestone floor, weathered, photorealistic, 2k"*).
4.  Select a resolution and format.
5.  Click **Generate Material**.
6.  The texture will be saved to your `Assets/Textures` folder, and a fully configured Unity Material referencing this texture will be created in the same folder. You can immediately drag and drop it onto any GameObject in your scene!

---

## 🆓 Zero Cost Generation (Pollinations AI)

By default, Texture Lab utilizes the **Pollinations AI** open API:
*   **No API Key Needed**: You don't need to register, configure, or copy API keys.
*   **100% Free & Unlimited**: Generate as many textures as you need for prototyping, testing, or final assets without hitting quotas or receiving bills.
*   **Alternative Paid Provider**: You can also switch the provider to **OpenAI (DALL-E 3)** in the Tool Settings if you have a paid OpenAI key.
