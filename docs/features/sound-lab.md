# 🔊 Sound Lab (Audio & SFX Generator)

**Sound Lab** is a game audio creation tool that generates game-ready sound effects (SFX) directly into your Unity project from simple text prompts.

---

## 🚀 How to Use

1.  Open **Tools > Brody AI > Sound Lab** (or access it from the Welcome Dashboard under Power Tools).
2.  Set up your **ElevenLabs API Key** in **Tool Settings > Sound Lab**.
3.  Choose a pre-defined **SFX Preset** (e.g. *Explosion, Footstep, Magic Spell, Gunshot, Sword Swing, UI Click*) or write a custom description in the prompt box (e.g. *"slow creaky wooden door opening in an empty room"*).
4.  Adjust settings like duration or sample rate.
5.  Click **Generate Sound**.
6.  The generated audio file will be imported directly as a `.mp3` or `.wav` **AudioClip** inside your Assets folder. You can preview it inside Unity immediately!

---

## 🔑 ElevenLabs Integration

Sound Lab uses the industry-leading **ElevenLabs Audio API**:
*   **Free Account**: You can sign up at [elevenlabs.io](https://elevenlabs.io) and get a free account.
*   **10,000 Free Credits/Month**: ElevenLabs' free tier includes 10,000 monthly credits. This is enough to generate roughly **100 high-quality custom sound effects** every month for free.
