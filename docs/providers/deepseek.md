# 🐳 Configuring DeepSeek

DeepSeek offers extremely affordable and capable coding models (`deepseek-coder` / `deepseek-chat`) that perform on par with top-tier commercial LLMs.

---

## 🔑 Setup Instructions

1.  Sign up at [platform.deepseek.com](https://platform.deepseek.com).
2.  Navigate to API Keys and create a new key.
3.  Open Unity and navigate to **Tools > Brody AI > Tool Settings**.
4.  In the **General** tab under the **Global Credential Vault**, paste your key into the **DeepSeek Key** field.
5.  Set your default agent to **DeepSeek** and select `deepseek-coder` or custom equivalent from the model menu.
