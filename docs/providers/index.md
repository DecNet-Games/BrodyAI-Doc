# 🔌 AI Providers Configuration

Brody AI decouples the editor plugin from specific LLM models. You can configure different provider brains to run Brody, allowing you to choose the best balance of cost, speed, intelligence, and privacy.

---

## ⚡ Supported Providers Directory

*   [**OpenAI**](./openai.html)
    Use GPT-4o or GPT-4o-mini for robust coding and general operations.
*   [**Google Gemini**](./gemini.html)
    Leverage Gemini 1.5 Pro and Flash with massive context slots.
*   [**Anthropic Claude**](./claude.html)
    Deploy Claude 3.5 Sonnet for highly advanced script refactoring.
*   [**DeepSeek**](./deepseek.html)
    Configure DeepSeek Coder for affordable high-tier programming logic.
*   [**OpenRouter**](./openrouter.html)
    Access a wide directory of models, including multiple **free models** with a single API key.
*   [**Groq**](./groq.html)
    Experience ultra-fast coding feedback loops using Groq's high-speed inference.
*   [**Ollama (Local Offline)**](./ollama.html)
    Run models locally on your GPU for 100% private, offline code generation.
*   [**Custom Provider**](./custom.html)
    Connect any OpenAI-compatible API endpoint (local proxies, LM Studio, custom servers).
*   [**ElevenLabs (Audio)**](./elevenlabs.html)
    Configure ElevenLabs keys to generate custom sound clips in Sound Lab.
